### 🚀 Featured Projects

**[Premier League Travel & Playstyle Network Analysis](https://github.com/syedabraash/Premier_League_Distance_Effect)**
Network-science + geospatial analysis of 5 seasons of Premier League data — does travel
distance predict away performance, and do clubs cluster by playstyle? Built with Python,
NetworkX, and scikit-learn; includes a full reproducible pipeline and honest handling of
data limitations.
`Python` `NetworkX` `scikit-learn` `Geospatial Analysis`

**[SpinMaster](https://github.com/syedabraash/SpinMaster_Final)**
Final-year AI table tennis coaching system combining TTNet (CNN+LSTM) for shot
classification with MediaPipe Pose for biomechanical analysis. Built over ~11 months with
a teammate, under academic supervision. Ongoing expansion: ball detection, scoring,
and player weakness detection.
`Computer Vision` `Deep Learning` `MediaPipe`

**[FPL Prediction Pipeline](https://github.com/syedabraash/PL_Predictor-model)**
A Premier League match prediction and Fantasy Premier League decision-support pipeline.
Uses XGBoost and Logistic Regression with engineered rolling features, EWM recency
weighting, and shot-based metrics across 18 clubs.
`XGBoost` `Feature Engineering` `Sports Analytics`
